# 136只出现一次的数字
## code
```javascript
/**
 * @param {number[]} nums
 * @return {number}
 */
var singleNumber = function(nums) {
    let result = 0; 
    for(let i = 0; i < nums.length; i++){
        result = result ^ nums[i];
    }
    return result;
};
```
