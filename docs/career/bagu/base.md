# 基础（网络，浏览器，各种乱七八糟，非js，非工程化）
## 一， 网络类问题
### 1. 输入 URL 到页面显示，中间发生了什么？
- 解析url  ——> 不合法 给搜索引擎， 合法：协议，域名，端口，等等
- 浏览器检查缓存： 强缓存未过期直接调磁盘，协商缓存通过请求响应头 通信
- dns查询，域名转ip地址，检测本机是否有缓存，分级检测 树式查询， 本地，再上级 —— 顶级等等，拿ip地址
- 获取MAC地址，类似通信层的事 
- tcp连接 去/回/去 三次
- tls 互相通信支持协议，版本号，证书，加密方法等
- 返回请求资源 状态吗响应头响应体等等
- 浏览器解析 - 构建dom，构建cssom， 生成渲染树，布局，绘制，gpu合成
